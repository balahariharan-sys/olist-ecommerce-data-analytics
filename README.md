# Brazilian E-Commerce Data Analytics Project

## Project Overview

This project analyzes Brazilian e-commerce data from Olist
to identify business trends, customer behavior, product
performance, and revenue patterns.

The project combines Python, PostgreSQL, and Power BI
to transform raw data into meaningful business insights.

## Business Objectives

- Analyze revenue and order performance.
- Identify top-performing product categories.
- Understand customer distribution across states.
- Evaluate customer and seller metrics.
- Build an interactive Power BI dashboard.

## Tools and Technologies

- Python
- Pandas
- Jupyter Notebook
- PostgreSQL
- SQL
- Power BI
- DAX

## Project Workflow

1. Data collection and inspection
2. Data cleaning and exploratory data analysis
3. Data loading and analysis using PostgreSQL
4. Business analysis using SQL queries
5. Dashboard development using Power BI
6. Business insights and conclusions

## Key Metrics

- Total Revenue
- Total Orders
- Total Customers
- Total Sellers
- Total Products
- Average Order Value
